# W02 Chamber Directory

This folder is ready to place at the root of the `wdd231` repository.

Published assignment URL:

`https://ahhs25.github.io/wdd231/chamber/directory.html`

## Included requirements

- Responsive navigation with wayfinding
- Local favicon and Open Graph image
- Reset, small-screen, and large-screen CSS in the required order
- Eight member records in `data/members.json`
- `fetch` with `async`/`await`
- Accessible grid/list view toggle; list view hides images
- JavaScript copyright year and last-modification date
- Lightweight local images and no CSS framework

Use VS Code Live Server when testing locally. Opening `directory.html` directly with a `file://` URL can block the JSON request.
